  <h2 style="margin-top: 2rem;">How It Works</h2>
  <ol>
    <li><strong>Generate</strong> — Our system produces multiple prompt candidates each day using LLM APIs (Hugging Face Inference or OpenAI).</li>
    <li><strong>Score</strong> — Each candidate is ranked on 4 metrics: clarity, specificity, structure, and usefulness (10-point scale).</li>
    <li><strong>Publish</strong> — The highest-scoring prompt is automatically published to this site via GitHub Actions at 8 AM WIB.</li>
    <li><strong>Use</strong> — Copy any prompt with one click and use it with your preferred AI model.</li>
  </ol>

  <h2 style="margin-top: 2rem;">What Makes a "God Tier" Prompt?</h2>
  <p>A god-tier prompt is engineered to maximize AI output quality with minimal ambiguity.
     These prompts:</p>
  <ul>
    <li>Have clear role assignment and context framing</li>
    <li>Use structured sections (task, constraints, output format)</li>
    <li>Include concrete examples and anti-patterns</li>
    <li>Specify output format for consistent, parseable results</li>
    <li>Are tested across multiple model families</li>
  </ul>
